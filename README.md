# LabTableView

## Configuración de conexión

La conexión se configura en la clase `DatabaseConnection`, dentro del paquete `com.desarrollo.papeleriacampus.conexiondb`.

Antes de ejecutar, ajusta las constantes `URL`, `USER` y `PASSWORD` según tu instalación local de PostgreSQL.

Se utiliza esta configuración siguiendo el ejemplo trabajado en clase y la indicación del docente para esta etapa.
